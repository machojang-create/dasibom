# 네이버 블로그 기본 세팅

발행 자동화를 돌리기 전에 한 번은 손으로 해야 하는 일입니다. 네이버는 스킨·카테고리를 바꾸는 API가 없습니다.

**순서대로 하세요.** 특히 2번(카테고리)을 건너뛰면 `publish_naver.mjs` 의 카테고리 선택이 통째로 실패합니다.

> 네이버는 관리 화면 메뉴 이름과 위치를 종종 바꿉니다. 아래 경로가 안 보이면 비슷한 이름을 찾으세요. 하는 일 자체는 그대로입니다.

---

## 0. 자산 만들기

```bash
cd blog
node gen_blog_assets.mjs
```

`out/assets/` 에 세 개가 나옵니다.

| 파일 | 크기 | 쓰는 곳 |
|---|---|---|
| `title.png` | 966×300 | PC 블로그 상단 타이틀 |
| `profile.png` | 400×400 | 프로필 이미지 |
| `side_banner.png` | 170×220 | 사이드바 배너 위젯 |
| `mobile_cover.png` | 1300×420 | 모바일 커버 |

색은 앱에서 그대로 가져왔습니다 — `#0e9d7d`(manifest 의 theme_color), 로고의 해·새싹. **블로그와 앱이 같은 얼굴이어야 합니다.** 처음 보는 사람이 두 개를 다른 서비스로 인식하면 유입이 새어나갑니다.

관리 화면에 표시되는 권장 크기가 위와 다르면 `config.json` 의 `blog_assets` 를 고치고 다시 돌리세요.

---

## 1. 검색 수집 허용 ← 제일 먼저

**관리 → 기본 설정 → 기본 정보 (또는 공개 설정)**

- 검색엔진 수집 **허용**

이게 꺼져 있으면 나머지가 전부 무의미합니다. 블로그를 만드는 이유 자체가 검색 유입인데 수집을 막으면 아무도 못 찾습니다. **가장 먼저 확인하세요.**

---

## 2. 카테고리 만들기 ← 자동화가 여기에 걸립니다

**관리 → 메뉴·글 관리 → 블로그**

아래 3개를 **글자 하나 안 틀리게** 만듭니다. 띄어쓰기 포함입니다.

```
돈과 혜택
건강과 영양
취미와 반려동물
```

각 카테고리에 무슨 글이 들어가는지는 `npm run cats` 로 확인할 수 있습니다.

`publish_naver.mjs` 가 이 이름으로 카테고리를 찾아 선택합니다. 하나라도 다르면 그 카테고리 글은 발행 시 기본 카테고리로 들어갑니다. 이름은 `config.json` 의 `naver.category_map` 에 있고, 바꾸고 싶으면 **양쪽을 같이** 바꿔야 합니다.

카테고리 순서는 위 순서대로 두세요. 방문자가 처음 보는 순서가 곧 우선순위입니다.

---

## 3. 블로그 정보

**관리 → 기본 설정 → 블로그 정보**

| 항목 | 값 |
|---|---|
| 블로그명 | 다시봄라이프 |
| 별명 | 다시봄 |
| 소개글 | 아래 참고 |
| 프로필 이미지 | `out/assets/profile.png` |
| 모바일 커버 | `out/assets/mobile_cover.png` |

소개글:

```
은퇴 이후의 하루에 필요한 정보를 씁니다.
돈과 혜택, 건강과 영양, 취미와 반려동물.
```

소개글은 검색 결과에 같이 노출됩니다. **무엇을 다루는 블로그인지 첫 줄에서 끝내세요.**

**소개글에 서비스 홍보를 넣지 마세요.** 무엇을 다루는 블로그인지만 밝힙니다. 운영 주체는 사이드바 배너와 글 끝 카드로 충분합니다.

---

## 4. 블로그 주제

**관리 → 기본 설정 → 블로그 정보 → 주제**

주제에 따라 네이버 주제별 페이지 노출이 달라집니다. 후보 둘 중 하나를 고르세요.

- **비즈니스·경제** — 돈과 혜택(40%)이 가장 큰 카테고리라 여기가 맞습니다.
- **건강·의학** — 건강과 영양(35%)과 맞고, 경쟁 블로그가 상대적으로 적습니다.
- **일상·생각** — 넓게 맞지만 경쟁이 셉니다.

비중대로면 **비즈니스·경제**가 맞습니다. 다만 경쟁이 부담되면 **건강·의학**으로 시작하고, 두세 달 뒤 유입 키워드를 보고 옮기세요. 주제는 나중에 바꿔도 기존 글에 문제 없습니다.

---

## 5. 스킨과 레이아웃

**관리 → 꾸미기 설정 → 스킨 선택**

- 흰 배경의 **심플한 기본 스킨**을 고르세요. 배경 무늬나 색이 강한 스킨은 우리가 만든 타이틀 이미지와 싸웁니다.

**관리 → 꾸미기 설정 → 레이아웃·위젯 설정**

- **2단 (본문 + 우측 사이드바)** 을 권합니다. 사이드바에 카테고리가 항상 보여야 다른 글로 넘어갑니다.
- 사이드바에 둘 것: **카테고리**, **프로필**, **최근 글**, 그리고 **배너 위젯**
- 배너 위젯: 관리 → 레이아웃·위젯 설정 → 위젯 직접등록. `out/assets/side_banner.png` 를 넣고 링크를 `https://dasibomlife.com` 으로. **글마다 링크를 붙이지 않는 대신 여기 하나만 답니다.**
- 뺄 것: 방문자 수 카운터, 달력, 시계 같은 장식 위젯. 초기에 방문자 수가 적으면 오히려 신뢰를 깎습니다.

**관리 → 꾸미기 설정 → 세부 디자인 설정 (리모콘)**

| 항목 | 값 |
|---|---|
| 타이틀 | 직접등록 → `out/assets/title.png` |
| 포인트 색 / 강조색 | `#0e9d7d` |
| 배경색 | `#F6FBF9` 또는 흰색 |
| 본문 글자 크기 | **한 단계 키우세요** |

**글자 크기를 키우는 건 취향이 아니라 요구사항입니다.** 독자가 시니어 본인입니다.

---

## 6. 댓글과 이웃

**관리 → 기본 설정 → 댓글·안부글**

- 댓글 **허용**. 독자가 남기는 질문이 그대로 다음 글의 주제가 됩니다.
- 스팸이 붙기 시작하면 그때 승인제로 바꾸세요. 처음부터 막을 필요는 없습니다.

이웃 신청은 열어두되 **먼저 신청하러 다니지는 마세요.** 이웃 수로 만드는 방문자는 검색 유입이 아니라 오래 남지 않습니다.

---

## 7. 확인

세팅이 끝나면 확인 한 번 하고 자동화로 넘어갑니다.

```bash
cd blog
npm run login          # 세션 저장
npm run draft          # 원고+이미지+검수 (발행 안 함)
```

원고가 마음에 들면 **첫 글은 수동으로** 발행해보세요. 카테고리가 제대로 잡히는지, 이미지가 깨지지 않는지 눈으로 확인하는 게 빠릅니다.

```bash
node publish_naver.mjs --post out/B01_xxx.json --headed --dry-run
```

`--dry-run` 은 발행 직전까지만 가고 화면을 `out/dryrun_*.png` 로 저장합니다. 카테고리와 태그가 맞게 들어갔는지 그 이미지로 확인하세요.
