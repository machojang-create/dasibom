# 여기서부터 이어서 하시면 됩니다

노트북 파란 창(PowerShell)에서 이 저장소 폴더로 들어가 `claude` 를 치고,
아래 내용을 그대로 붙여넣으시면 그 창의 제가 이어서 합니다.

---

## 지금 상태

| | |
|---|---|
| 원고 | **14편 완성** · 평균 3,000자 · 검수 차단 0건 |
| 이미지 | **81장 완성** (대표 14 + 정보 카드 67) |
| 일러스트 | **0장** · 자리와 그림 지시문은 89개 다 잡혀 있음 |
| 주제 큐 | 162편 (약 54주치) |
| 네이버 세팅 | **아직 안 함** |

원고는 `blog/out/*.json` 에 있습니다. 이미지는 `blog/out/`, `blog/out/figs/` 입니다.

## 바로 할 수 있는 것

```bash
cd blog

# 일러스트 89장 (tools/gemini.key 를 그대로 씁니다)
npm run illust

# 먼저 3장만 뽑아 화풍 확인
node gen_illust.mjs --all --limit 3

# 원고를 눈으로 확인
node preview_post.mjs --post out/B01_*.json
```

## 남은 일 (순서대로)

1. **일러스트 뽑기** — `npm run illust`. 무료 한도에 걸리면 다음 날 같은 명령
2. **네이버 관리 화면 세팅** — 카테고리 7개를 글자 하나 안 틀리게. `SETUP_NAVER.md` 참고
   ```
   정책과 지원금 / 건강과 의료 / 취미와 여가 / 요리와 살림
   스마트폰과 디지털 / 마음과 관계 / 자서전과 기록
   ```
3. **네이버 로그인** — `npm run login` (브라우저에서 직접 로그인)
4. **첫 글 눈으로 확인 발행**
   ```bash
   node publish_naver.mjs --post out/B01_*.json --headed --dry-run
   ```
   네이버 에디터 DOM 은 자주 바뀝니다. 실패하면 `lib/selectors.mjs` 만 고치면 됩니다

## 읽을 것

- `blog/README.md` — 원칙, 카테고리, 문체 규칙, 검수 규칙
- `.claude/skills/blog-post/SKILL.md` — 원고 쓰는 기준 (친절·예시·감성·분량·이미지)
- `blog/out/B01_기초연금-*.json` — **톤의 기준이 되는 원고**

## 이 창(클라우드)에서 못 했던 것

웹·앱에서 연 세션은 클라우드에서 돌아 노트북 파일이 안 보입니다.
그래서 `tools/gemini.key` 를 못 읽어 일러스트를 못 뽑았고, 네이버도 막혀 있었습니다.
노트북 터미널에서 연 창에서는 둘 다 그냥 됩니다.
